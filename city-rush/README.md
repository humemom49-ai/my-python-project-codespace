# City Rush: Midnight Run

An original little browser driving game. Dodge traffic, collect cash, and
survive as long as you can. Three collisions end the run.

Open `index.html` in a browser, or from the repository root run:

```bash
python -m http.server 8000 --directory city-rush
```

Then visit the server in your browser. Use the arrow keys or WASD to drive;
on a touch screen, use the on-screen controls. Press **Play Again** to restart.
The game uses no external images or libraries. Fonts use a web font when
available and fall back to system fonts otherwise.
