
# Haikus for Codespaces

This is a quick node project template for demoing Codespaces. It is based on the [Azure node sample](https://github.com/Azure-Samples/nodejs-docs-hello-world). It's great!!!

Point your browser to [Quickstart for GitHub Codespaces](https://docs.github.com/en/codespaces/getting-started/quickstart) for a tour of using Codespaces with this repo.

## Library program

Run the interactive library catalog with `python library.py`. Use `add`,
`lend`, `return`, `list`, or `quit` at the prompt. The catalog is kept in
memory and is cleared when the program exits.

Run the library tests with `python -m unittest discover -s tests`.

## Locker example

Run `python rung_4.py` to see a locker assignment example. Its
`assign_locker` and `release_locker` functions can also be imported into
other Python programs.
